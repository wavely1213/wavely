# 단체 히어로 사진 만들기 (2026-11-13, D-084)

홈 맨 위 큰 사진(관리자 › 홈페이지 내용 › 메인 '맨 위 큰 사진', `home.hero.image`)용 26-27 단체 사진을 선수 누끼로 합성한다.
사이트 코드와 무관한 오프라인 도구다(파이썬 numpy / opencv-python-headless / scipy / pillow, 저장소 의존성 아님).

1. `refine.py <누끼 폴더> <출력 폴더>` — 누끼 테두리 다시 따기. 반투명 테두리에 원래 흰 배경색이 섞여 어두운 바탕에서 빛나던 것을
   몸 안쪽 색으로 다시 칠하고(alpha 0.98 이상을 2px 깎은 core 기준 가장 가까운 색), alpha 를 0.25 아래 잘라 1px 깎고 0.9px 부드럽게.
2. `compose.py <다시 딴 폴더> <bbox.json> <출력.jpg> [seed]` — 3200x1500, 가운데 주장 크게, 양옆 부주장, 나머지는 겹(A~D) 격자에 엇갈려 놓고
   얼굴(이마~턱)이 앞사람에 6% 넘게 가리면 그 자리는 버림. 경기 카드(오른쪽 아래)와 문구(왼쪽 아래) 자리에는 얼굴을 두지 않음.
   bbox.json = 누끼마다 {top, head_cx, head_w}(위 260px 안 머리 폭). 사람이 바뀌면 ASSIGN / CAP / VCS 를 고친다.
3. `extend.py` — 이미 만든 1920x1080 단체 사진을 히어로 비율에 맞게 검정으로 넓힐 때(위 T, 양옆 S, 아래 B).

히어로는 cover + object-position center 30%(Hero.module.css). 얼굴이 모든 PC 폭에서 보이는 범위는 캔버스 x 500~2700, y 230~1000 (1280 이상은 x 330~2870).
