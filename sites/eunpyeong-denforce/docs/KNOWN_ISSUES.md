- **해결 방향**: Vercel → eunpyeong-denforce → Settings → Git → Connect Git Repository → wavely1213/wavely (Root Directory 는 이미 sites/eunpyeong-denforce). 연결 후 Production Branch 를 운영 브랜치로 지정.


## I-010 | 2026-10-15 | Supabase Free 플랜 자동 백업 없음 · 7일 미사용 시 일시정지

## I-009 | 2026-10-15 | 관리자 비밀번호 재설정 화면 없음

## I-008 | 2026-10-15 | 공개 캐시 갱신이 서버 인스턴스 간 즉시 전파되지 않을 수 있음
- **상태**: 보류(1분 상한으로 완화)
- **심각도**: 낮음
- **증상/내용**: 'use cache' 기본 핸들러는 인스턴스 메모리. updateTag 는 저장을 처리한 인스턴스에 즉시 반영되고, 다른 인스턴스는 cacheLife('minutes') 로 최대 1분 뒤 반영 (D-009).
- **해결 방향**: 필요 시 'use cache: remote' 또는 공유 캐시 핸들러.


## I-007 | 2026-10-15 | KFA고딕 웹 사용 조건 미확인
- **상태**: 열림
- **심각도**: 중간 (라이선스)
- **증상/내용**: 폰트 메타데이터 "Copyright KFA. All rights reserved. (Sandoll)". 경기도축구협회가 시·군협회 엠블럼 제작용으로 배포한 파일을 제3자 블로그 미러에서 받음. 웹폰트 사용·재배포 허용 여부 명시 없음.
- **위치**: `src/fonts/KFAGothic-*.woff2`, `src/app/layout.tsx`
- **해결 방향**: 공개 전 대한축구협회(또는 한국풋살연맹) 확인. 불가 시 Pretendard 등 OFL 서체로 교체.
