# 파장 WAVELENGTH

기계화 시대 종스크롤 슈팅. 1942 계열의 기본 시스템 위에
**탑승자 · 기체 · 장비 · 치장 · 스토리**로 게임성을 얹었다.

> 기계화 3세기. 대역을 따라 내려온 **군체**가 도시를 덮었다.
> 정격관제국은 단독 출격기 「파장-7」에 조종사 하나를 태워 대역 위로 올려보낸다.
> 목표는 군체를 움직이는 송신 — 근원을 끊는 것.

- 단일 파일: `game/index.html` (외부 요청 0 — 폰트·이미지·사운드 전부 인라인 또는 코드 생성)
- 와벨리 앱 코드(`src/`)와 완전히 분리되어 있다. 앱 의존성 없음, 빌드 없음.

## 실행

```
# 그냥 열기
open game/index.html

# 또는 로컬 서버
npx http-server game -p 8080
```

## 시스템

### 코어 루프
웨이브 6개 → 보스(증폭체) → 다음 구역. 피격 시 하트 1 감소, 0이면 런 종료.
런 중 모은 **코어**는 죽어도 보존되고, 격납고에서 소비한다.

**콤보**가 중독성의 축이다. 2.2초 안에 다음 처치를 이으면 콤보가 쌓이고,
5킬마다 배율이 +0.5(최대 ×5). 피격 시 즉시 0. 점수는 배율 곱으로 들어간다.

### 탑승자 (회피율 · 연사력 · 보급 아이템)
탑승자를 바꾸면 **떨어지는 보급품 자체가 달라진다**. 스토리 대사도 탑승자별로 갈린다.

| | 회피 | 연사 | 보급품 | 해금 |
|---|---|---|---|---|
| P-01 「스트레이」 유리 카렌 | 6% | 112% | 정비 부품 — 내구 1 회복 | 기본 |
| P-02 「할로우」 진 나오미 | 20% | 94% | 코어 뭉치 — 코어 5 | 320 |
| P-03 「토치」 서 도윤 | 3% | 125% | 과부하 셀 — 8초간 연사 +45% | 440 |
| P-04 「앵커」 문 세라 | 10% | 100% | 예비 탄두 — 폭탄 1 보급 | 2구역 + 360 |

회피는 피격 시 굴려서 성공하면 내구도 콤보도 잃지 않는다(짧은 무적 + 잔상 연출).

### 기체 (공격력 · 이동속도 · 연사력 · 부가효과)
기체는 **실루엣도 각각 다르다**. 도장은 그 위에 얹히는 색.

| | 공격 | 기동 | 연사 | 부가효과 | 해금 |
|---|---|---|---|---|---|
| TR-04 그레일 (표준 강습) | 100% | 100% | 100% | 정격 출력 — 콤보 배율 상한 ×6 | 기본 |
| HV-09 보어 (중장 돌파) | 134% | 82% | 88% | 천공 탄심 — 관통 +1 | 480 |
| SL-02 윔지 (경량 정찰) | 84% | 128% | 116% | 견인장 확대 — 회수 범위 ×1.8 | 420 |
| XN-11 케이지 (시제 실험기) | 108% | 96% | 100% | 육각 차폐 — 6초마다 피탄 1회 무효 | 3구역 + 600 |

### 장비 (3슬롯 × 5레벨)
| 슬롯 | 효과 |
|---|---|
| 무기 코일 | 1발 → 2발 → 3확산 → 5확산 → 5확산+중앙 관통 |
| 추진 엔진 | 기동력 + 연사 속도 |
| 차폐막 | 최대 내구 + 폭탄 보유량 |

강화 비용은 `upCost(lv) = round(40 · lv^1.75 / 5) · 5`.

**최종 스펙 = 장비 × 기체 × 탑승자.** `stats()` 한 곳에서 합산하고, 타이틀의 「현재 편성」이 그 결과를 그대로 보여준다.

피격 판정 순서는 **육각 차폐 → 탑승자 회피 → 실제 피해**.

### 치장 (성능 영향 없음)
- **도장** 4종 — 정격(기본) / 창공 / 초원 / 흑요(3구역 돌파 시 해금)
- **배기 궤적** 4종 — 잔불 / 이온 / 잔향(위상 잔상) / 개화

타이틀 화면의 기체 프리뷰가 **탑승 중인 기체 + 도장 + 궤적** 조합을 실시간으로 렌더한다.

### 스토리
구역마다 [기록 나레이션 · 관제 지시]는 고정, **마지막 한 줄은 탑승자마다 다르다.**
탑승자 4명 × 5구역 + 엔딩까지 24줄. 탑승자를 바꾸면 격납고 › 기록의 지난 대사도 그 목소리로 다시 읽힌다.

**처음 들어가는 구역에서만** 재생되어 재도전 흐름을 끊지 않는다.
5구역 클리어 후에는 무한 모드 「잔향」이 열린다.

### 저장
`localStorage["wavelength.save.v1"]` — 코어, 최고 점수, 돌파 구역, 장비 레벨,
탑승자·기체·치장의 보유 및 장착, 본 대사, 도감.
없는 필드는 기본값으로 채워지므로 구버전 저장도 그대로 이어진다. 저장이 막힌 환경에서도 게임은 돌아간다(try/catch).

## 디자인

> 디자인 규칙과 **남은 작업 목록**은 [`DESIGN_GUIDE.md`](./DESIGN_GUIDE.md)에 따로 정리했다.
> UI·아트를 손대기 전에 그 문서의 1장(확정 규칙)을 먼저 읽는다.

**기계화 시대의 제도적·산업 규격 룩.** 위험 표지 띠, 형식번호(TR-04 / P-01), 격벽 이음새와 리벳,
계기 모서리 표식, 육각 차폐 — 화면 자체가 관제국이 지급한 계기판처럼 읽히게 했다.
군체는 전부 조립품으로 그린다(장갑판 + 이음새 + 추진기 노즐).

Claude(Anthropic) 브랜드 팔레트를 게임 자체 토큰으로 쓴다. 와벨리 앱 토큰(스카이블루)과는
의도적으로 분리 — 앱 UI가 아니라 별개 제품이다.
마침 이 팔레트가 기계화에 잘 맞는다: `#d97757` 녹슨 경고색, `#788c5d` 올리브드랩, `#b0aea5` 건메탈.

색은 **의미에 1:1로 고정**되어 화면이 시끄러워도 읽힌다.

| 토큰 | 값(라이트 / 다크) | 의미 |
|---|---|---|
| `--c-signal` | `#d97757` | 플레이어 · 아군 탄 |
| `--c-drift` | `#5d8fc2` / `#6a9bcc` | 적 · 적 탄 · 보스 |
| `--c-moss` | `#788c5d` / `#94ab72` | 코어 · 폭탄 등 획득물 |
| `--c-dust` | `#b0aea5` | 계기 · 배경 파형 |
| `--c-field` | `#faf9f5` / `#141413` | 플레이필드 바닥 |

두 테마를 모두 디자인했다. 다크는 잉크 필드, **라이트는 종이 필드**로 적이 뒤집힌다.
`prefers-color-scheme`과 `:root[data-theme]` 양방향 모두 대응.

타이포는 HUD·메뉴에 지오메트릭 산세리프, 스토리 대사에만 세리프를 써서 계기판과 내러티브를 갈라놓았다.
배경은 별 대신 **아래로 흐르는 파형** — 주파수 대역이라는 소재에서 가져왔다.

## 늘리는 법

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 탑승자 추가 | `PILOTS` + `STORY_PILOT[id]`(구역별 대사 + `end`). 새 보급품이면 `SUPPLY`와 `collect()`에 종류 추가 |
| 기체 추가 | `FRAMES` + `HULL[id]`(꼭짓점 배열) + `drawFrame()`의 이음새·표식 분기. 새 `perk`는 `stats()`에서 해석 |
| 구역 추가 | `STAGES` + `STORY_FIXED` + `STORY_PILOT`의 해당 번호 (없으면 무한 모드로 자동 처리) |
| 군체 추가 | `spawnEnemy()`의 스탯 · `update()`의 이동 분기 · `drawEnemy()`의 실루엣 · `CODEX` |
| 웨이브 편성 | `genWave(stage, i)` — 포메이션 이름과 수량만 바꾸면 된다 |
| 무기 · 장비 | `WEAPON` / `ENGINE` / `SHIELD` 배열 (레벨 상한은 `MAXLV`) |
| 치장 추가 | `SKINS` / `TRAILS` + `drawTitleShip()`·`paintSwatch()`의 궤적 분기 |
| 난이도 | `hpScale()`, 보스 HP(`startBoss`), 적 탄속의 `G.stage` 계수 |

기체 실루엣은 `HULL` 꼭짓점 배열 + `drawFrame(ctx, id, x, y, scale, color)` 한 곳에만 있다 —
필드·타이틀 프리뷰·격납고 카드·치장 스와치가 전부 이 함수를 공유한다.

### 기체 렌더 — 2단 LOD

`drawFrame()`은 배율을 보고 두 경로로 갈린다.

| 배율 | 쓰이는 곳 | 그리는 것 |
|---|---|---|
| `sc < 1` | 잔향 궤적의 잔상 | 단색 + 외곽선 |
| `sc >= 1` | 게임 중 기체(1.0) · 격납고 카드(2.9) · 타이틀(2.4) | 금속 그라디언트 → 내부 베벨 → 패널 이음새 → 방열구 → 스텐실 → 노즐 발광 → 각진 캐노피 → 형식별 표식 |

세부는 `DETAIL[id]`(이음새 · 방열구 · 노즐 · 데칼 좌표)에만 들어 있어, 새 기체는 `HULL` + `DETAIL`
두 줄만 추가하면 같은 마감을 그대로 받는다. 보스도 같은 처리(그라디언트 + 베벨 + 분할선 + 코어 발광)를 쓴다.

작업하며 두 가지 함정을 밟았고, 새 아트를 붙일 때도 같은 규칙이 필요하다.

- **구조선은 화면 좌표로.** 외곽선·이음새 굵기를 모델 좌표(`lineWidth = 1.1`)로 두면 확대할 때
  테두리도 같이 굵어져 스티커처럼 보인다. `const lw = 1.3 / sc` 로 잡고 그 배수를 쓴다.
  면(그라디언트·베벨)만 모델 좌표를 따른다.
- **하드웨어 색에 `C.fg`를 쓰지 않는다.** 테마에 따라 뒤집히므로 다크에서 노즐·포드가 하얘진다.
  금속 부품은 `shade(base, -0.5 ~ -0.66)` 처럼 도장색 파생으로 잡는다.
스펙 합산도 `stats()` 한 곳에서만 일어나므로, 새 부가효과는 그 안에 한 줄 추가하면 전 화면에 반영된다.
