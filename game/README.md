# 파장 WAVELENGTH

종스크롤 슈팅. 1942 계열의 기본 시스템 위에 **장비 · 치장 · 스토리**로 게임성을 얹었다.

- 단일 파일: `game/index.html` (외부 요청 0 — 폰트·이미지·사운드 전부 인라인 또는 코드 생성)
- 와벨리 앱 코드(`src/`)와 완전히 분리되어 있다. 앱 의존성 없음, 빌드 없음.

## 실행

```
# 그냥 열기
open game/index.html

# 또는 로컬 서버
npx http-server game -p 8080
```

## 조작

| | |
|---|---|
| 이동 | 드래그(마우스·터치) / 방향키 · WASD |
| 사격 | 자동 |
| 폭탄 | Space, 또는 우하단 BOMB 버튼 |
| 일시정지 | Esc, 또는 HUD의 II |

터치로 잡으면 기체가 손가락 위쪽으로 오프셋되어 손에 가리지 않는다.

## 시스템

### 코어 루프
웨이브 6개 → 보스(증폭체) → 다음 구역. 피격 시 하트 1 감소, 0이면 런 종료.
런 중 모은 **코어**는 죽어도 보존되고, 격납고에서 소비한다.

**콤보**가 중독성의 축이다. 2.2초 안에 다음 처치를 이으면 콤보가 쌓이고,
5킬마다 배율이 +0.5(최대 ×5). 피격 시 즉시 0. 점수는 배율 곱으로 들어간다.

### 장비 (3슬롯 × 5레벨)
| 슬롯 | 효과 |
|---|---|
| 무기 코일 | 1발 → 2발 → 3확산 → 5확산 → 5확산+중앙 관통 |
| 추진 엔진 | 기동력 + 연사 속도 |
| 차폐막 | 최대 내구 + 폭탄 보유량 |

강화 비용은 `upCost(lv) = round(40 · lv^1.75 / 5) · 5`.

### 치장 (성능 영향 없음)
- **기체 도장** 4종 — 델타(기본) / 창공 / 초원 / 흑요(3구역 돌파 시 해금)
- **배기 궤적** 4종 — 잔불 / 이온 / 잔향(위상 잔상) / 개화

타이틀 화면의 기체 프리뷰가 장착 중인 조합을 실시간으로 렌더한다.

### 스토리
구역별 진입 대사 5편. **처음 들어가는 구역에서만** 재생되어 재도전 흐름을 끊지 않고,
지난 대사와 적 도감은 격납고 › 기록에서 다시 읽는다.
5구역 클리어 후에는 무한 모드 「잔향」이 열린다.

### 저장
`localStorage["wavelength.save.v1"]` — 코어, 최고 점수, 돌파 구역, 장비 레벨, 보유·장착 치장, 본 대사, 도감.
저장이 막힌 환경에서도 게임은 그대로 돌아간다(try/catch).

## 디자인

Claude(Anthropic) 브랜드 팔레트를 게임 자체 토큰으로 쓴다. 와벨리 앱 토큰(스카이블루)과는
의도적으로 분리 — 앱 UI가 아니라 별개 제품이다.

색은 **의미에 1:1로 고정**되어 화면이 시끄러워도 읽힌다.

| 토큰 | 값(라이트 / 다크) | 의미 |
|---|---|---|
| `--c-signal` | `#d97757` | 플레이어 · 아군 탄 |
| `--c-drift` | `#5d8fc2` / `#6a9bcc` | 적 · 적 탄 · 보스 |
| `--c-moss` | `#788c5d` / `#94ab72` | 코어 · 폭탄 등 획득물 |
| `--c-dust` | `#b0aea5` | 계기 · 배경 파형 |
| `--c-field` | `#faf9f5` / `#141413` | 플레이필드 바닥 |

두 테마를 모두 디자인했다. 다크는 잉크 필드, **라이트는 종이 필드**로 적이 뒤집힌다.
`prefers-color-scheme`과 `:root[data-theme]` 양방향 모두 대응.

타이포는 HUD·메뉴에 지오메트릭 산세리프, 스토리 대사에만 세리프를 써서 계기판과 내러티브를 갈라놓았다.
배경은 별 대신 **아래로 흐르는 파형** — 주파수 대역이라는 소재에서 가져왔다.

## 늘리는 법

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 구역 추가 | `STAGES` + `STORY` (없으면 무한 모드로 자동 처리) |
| 적 추가 | `spawnEnemy()`의 스탯 · `update()`의 이동 분기 · `drawEnemy()`의 실루엣 · `CODEX` |
| 웨이브 편성 | `genWave(stage, i)` — 포메이션 이름과 수량만 바꾸면 된다 |
| 무기 · 장비 | `WEAPON` / `ENGINE` / `SHIELD` 배열 (레벨 상한은 `MAXLV`) |
| 치장 추가 | `SKINS` / `TRAILS` + `drawTitleShip()`·`paintSwatch()`의 궤적 분기 |
| 난이도 | `hpScale()`, 보스 HP(`startBoss`), 적 탄속의 `G.stage` 계수 |

선체 실루엣은 `drawShip(ctx, x, y, scale, color)` 한 곳에만 있다 —
필드·타이틀 프리뷰·치장 스와치가 전부 이 함수를 공유한다.
