# K-pop 작곡 노트 (kpop-songwriter)

작곡 프로그램을 몰라도 K-pop 곡을 만들 수 있게 돕는 브라우저 앱입니다.
claude.ai 아티팩트로 실행되고, AI 기능은 내 Claude 사용량을 씁니다 (API 키 없음).

## 할 수 있는 것
- **발매까지 진행 단계**: 컨셉→가사→편곡→멜로디→Suno→마스터링→발매 준비, 다음 할 일 안내
- **AI로 곡 초안 한 번에**: 주제만 적으면 가사·편곡·멜로디·Suno 스타일까지 차례로 채움
- **컨셉·멤버**: 주제, 분위기, 한/영 비율, 멤버 포지션과 보컬 톤
- **구조·가사**: 구조 템플릿, 파트 자동 분배, AI 작사, 줄별 음절 수·라임 표시, 영어 훅 추천, AI 가사 검토
- **가사 점수**: 라임·줄 길이·훅 반복을 자동 채점, 낮은 섹션을 AI로 고쳐 점수가 오른 것만 반영
- **편곡**: 빠르기·키, 섹션별 코드 진행(느낌으로 선택)·에너지·악기·드럼·베이스, 드럼 직접 찍기, AI 편곡
- **멜로디**: 가사에 맞춘 AI 멜로디 + 피아노롤 편집 (스케일 안의 음만 표시)
- **사운드**: 악기 10종 음색·밝기·볼륨 (실제 악기 샘플, 출처는 assets/samples/CREDITS.md)
- **레퍼런스**: 참고 곡 오디오 분석(BPM·키·저음·에너지 흐름) + 메모 → AI 편곡에 반영
- **마스터링**: Suno 완성곡을 -14 LUFS·-1 dBTP·44.1kHz WAV로 (발매 규격)
- **내보내기**: Suno 가사·스타일 복사, zip 패키지(가사·스타일·MIDI·WAV 데모·프로젝트·안내서)
- **앨범·발매**: 곡 묶기, 메타데이터·크레딧, 3000×3000 커버, 발매 일정표, AI 홍보 문구, 발매 전 점검, 유통사 제출 패키지(zip)
- **내 취향**: AI 결과 👍/👎·고친 내용을 배워 모든 AI 요청에 반영, 기록 JSONL 내보내기
- **버전**: 메모와 함께 저장·복원

## 개발
```bash
npm install
npm run build       # dist/index.html (claude.ai 아티팩트)
npm run build:web   # dist-web/music/ (mulgyeol.kr/music 웹사이트)
npm test        # 빌드 + 단위 + 엔진 + 화면 테스트 (Playwright 전역 설치 필요)
```

작업 지침은 [AGENTS.md](AGENTS.md)와 [docs/](docs/)를 따릅니다.
