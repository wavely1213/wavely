# K-pop 작곡 노트 (kpop-songwriter)

작곡 프로그램을 몰라도 K-pop 곡을 만들고 발매까지 갈 수 있게 돕는 브라우저 앱입니다.
claude.ai 아티팩트로 실행되고, AI 기능은 내 Claude 사용량을 씁니다 (API 키 없음).
같은 코드를 웹사이트(mulgyeol.kr/music, 설치형·오프라인)로도 빌드합니다 (웹에서는 AI 꺼짐).

## 할 수 있는 것

**곡 만들기**
- **발매까지 진행 단계**: 컨셉→가사→편곡→멜로디→Suno→마스터링→발매 준비, 다음 할 일 안내
- **컨셉 아이디어·원클릭 초안**: 아이디어가 없으면 AI가 컨셉 3개 제안, 고르면 가사·편곡·멜로디·Suno 스타일까지 차례로 채움
- **구조·가사**: 구조 템플릿, 파트 자동 분배, AI 작사, 줄별 음절 수·라임 표시, 영어 훅 추천, AI 가사 검토
- **가사 점수**: 라임·줄 길이·훅 반복 자동 채점(내 가사로 기준 보정), 낮은 섹션을 AI로 고쳐 점수가 오른 것만 반영
- **발매 전 가사 점검**: 유명 곡과 비슷한 줄(참고용), 맞춤법·띄어쓰기
- **편곡**: 빠르기·키, 섹션별 코드 진행·에너지·악기·드럼·베이스, 드럼 직접 찍기, AI 편곡
- **멜로디**: 가사에 맞춘 AI 멜로디(멤버 음역 안), 피아노롤·키보드 편집, 가사 음절 넣기
- **사운드·레퍼런스**: 실제 악기 샘플 음색, 참고 곡 오디오 분석(BPM·키·저음·고음·에너지) → AI 편곡·마스터링에 반영
- **Suno**: 가사·스타일 복사(글자 수 한도), 스타일 변형 A/B/C, 일본어·영어 번안 가사(음 수 맞춤), 제작 패키지 zip(MIDI·데모 WAV)

**마스터링**
- Suno 완성곡을 -14 LUFS·-1 dBTP·44.1kHz WAV로 (발매 규격, ffmpeg로 교차 확인)
- 테이크 여러 개 비교(BPM·키·길이), 레퍼런스 음색 맞추기, 곡 끝 자르기(들으며 "여기서 끝내기"), 소리 점검(클리핑·스테레오 상관), 숏폼 하이라이트 15·30초

**앨범·발매**
- 진행 단계 7개 + 다음 할 일, 곡 묶기·앨범의 새 곡(멤버 이어받기)·Inst. 버전·트랙 순서 추천·곡 사이 이어 듣기, 메타데이터·크레딧·지분(스플릿) 시트
- 3000×3000 커버, 싱크 가사(LRC) 맞추기, 발매 일정표(캘린더 .ics), AI 홍보 문구·플레이리스트 피칭
- 발매 전 점검(규격·음량 차이·크레딧·지분·싱크·가사 점검·제목 표기), 유통사 제출 패키지(zip: 마스터·커버·CSV·가사·LRC·가사집·지분 시트)
- 발매 후 성과 기록 → 반응 좋은 곡의 특징을 다음 곡 AI에 반영

**학습·안전**
- **내 취향**: 👍/👎·줄 단위 ♥·고친 내용을 배워 모든 AI 요청에 반영, 기록·선호 쌍 JSONL 내보내기(파인튜닝용)
- **버전**: 메모와 함께 저장·복원·지금과 비교, 되돌리기(Ctrl+Z)·다시 하기(곡·앨범)
- **전체 백업·복원**: 모든 곡·앨범·취향을 파일 하나로 (덮어쓰지 않고 합침)
- **용어 도움말**: BPM·LUFS·ISRC·LRC·지분 등 옆의 "?"

## 개발
```bash
npm install
npm run build       # dist/index.html (claude.ai 아티팩트)
npm run build:web   # dist-web/music/ (mulgyeol.kr/music 웹사이트, PWA)
npm run check       # 문법·안 쓰는 import·console.log 점검 (의존성 없음)
npm test            # 점검 + 빌드 + 단위 + 엔진·마스터링 + AI 흐름 + 화면 + 웹 + 접근성 + 성능 (Playwright·ffmpeg 필요)
```
