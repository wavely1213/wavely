## 1. 목표

작곡 프로그램을 모르는 사람도 **컨셉 → 가사 → 작곡·편곡 → 음원(Suno) → 마스터링 → 앨범 발매**까지
한 곳에서, 최소 반자동으로 끝낸다. 웹사이트 `mulgyeol.kr/music`으로 제공한다.

## 2. 기둥 4개

### A. 웹사이트화 — mulgyeol.kr/music
- 같은 코드로 두 가지 실행 환경: **claude.ai 아티팩트**(지금) / **웹사이트**(정적 사이트).
- `platform` 계층이 차이를 흡수한다: AI 호출, 저장, 파일 내려받기, 사용자.
  - 아티팩트: `sample`·`db`·`downloads`·`user` capability
  - 웹: AI는 서버 경로(`/music/api/ai`, Vercel 함수 + 서버 키) — **설정 전까지는 AI 기능에 "claude.ai 버전에서 사용" 안내**. 저장은 브라우저(localStorage/IndexedDB) → 이후 Supabase(wavely와 같은 프로젝트, `music_` 테이블, 본인만 읽기·쓰기). 다운로드는 일반 파일(.wav·.mid 그대로).
- 배포: 이 폴더를 별도 Vercel 프로젝트로 배포하고, mulgyeol.kr을 서비스하는 `wavely-web`의 vercel.json에 `/music/:path*` 리라이트 한 줄 추가. (wavely-web은 이 세션에서 접근 불가 → 소유자 작업)

### B. AI "학습" — 내 취향을 배우는 작사·작곡
- 모델 자체 학습(파인튜닝)은 이 환경에서 불가. 대신 **취향 학습**:
  - 결과마다 👍/👎, 사용자가 고친 전후를 기록 (피드백 로그)
  - 쌓인 기록에서 **취향 프로필**을 만든다: 좋아한 가사 예시, 자주 고치는 방향, 피할 표현, 선호 BPM·키·코드·악기
  - 모든 AI 프롬프트에 프로필과 좋아한 예시(few-shot)를 넣는다
  - 피드백 로그를 JSONL로 내보내기 → 나중에 파인튜닝 데이터로 재사용 가능

### C. 최적화 — 자동 평가와 개선 루프
- 가사 자동 채점: 라임 밀도, 줄별 음절 균형, 훅 반복, 한/영 비율 목표와 차이, 파트 분배 균형 → 점수 낮은 섹션을 "다시 쓰기 추천"
- 편곡·멜로디 점검: 멜로디 음역(가수 음역 밖), 섹션 간 에너지 대비, 코러스 진입 변화
- 마스터링 QC 자동(이미 있음)
- 앱 성능 예산: 번들 크기, 렌더·마스터링 시간을 테스트에서 감시

### D. 앨범 발매 반자동화
1. **앨범 프로젝트**: 곡 묶기, 트랙 순서, 타이틀곡, 앨범 종류(싱글/EP/정규)
2. **메타데이터**: 아티스트명, 앨범명, 장르, 발매 예정일, 언어, 작사·작곡·편곡 크레딧, 레이블, ISRC/UPC(유통사가 발급 — 받은 뒤 입력), AI 사용 여부 표기
3. **커버 아트**: 3000×3000 JPG 템플릿 생성(앨범명·아티스트·컨셉 색) + 직접 업로드
4. **유통사 제출 패키지**: 마스터 WAV(트랙 번호·제목 파일명), 커버, 메타데이터 CSV, 가사 TXT, 크레딧 시트 → zip
5. **발매 일정표**: 발매일 기준 D-28(유통 신청)~D+14(홍보) 체크리스트 자동 생성
6. **홍보 문구**: 앨범 소개·트랙 설명·SNS 카피를 AI로 초안
7. **발매 전 점검표**: 음원 규격, 커버 규격, 메타데이터 누락, 저작권(작사·작곡 등록), AI 생성 음원 정책 확인
