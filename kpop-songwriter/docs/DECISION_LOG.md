## D-019 | 2026-10-08 | 버전 보관: '최근 N개' 대신 자동 저장을 먼저 지운다
- **상태**: 채택
- **맥락**: 버전이 가득 찬 상태(웹 8개)에서 가장 오래된 버전을 복원하면 복원 전 자동 저장이 생기면서 바로 그 버전이 지워졌고, 복원을 거듭하면 자동 저장이 이름 붙인 버전을 밀어냈다.
- **결정**: 넘칠 때 방금 만든 것과 복원하는 버전은 두고, '복원 전 자동 저장'(auto)부터, 그다음 이름 붙인 버전을 오래된 순으로 지운다. 이름 붙인 버전이 지워질 복원은 목록에 미리 알린다.
- **이유**: 버전은 Suno·큰 AI 수정 전의 안전장치라, 사용자가 이름 붙인 체크포인트가 자동 사본보다 중요하다.
- **버린 대안**: 그대로 최근 N개 — 조용한 데이터 손실 / 보관 수 늘리기 — 브라우저 저장 공간(약 5MB)이 모자람.
- **영향/제약**: 목록이 엄격한 '최근 N개'가 아니다(오래된 이름 붙인 버전이 새 자동 저장보다 오래 남음). 예전 자동 저장은 메모('복원 전 자동 저장')로 알아본다.
