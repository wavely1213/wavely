# 사운드 출처 (Sample credits)

이 앱의 악기 샘플은 아래 자료를 3반음 간격으로 골라 묶은 것입니다. 이 샘플로 만든 음악의 상업적 이용은 각 라이선스 조건(저작자 표시)을 따릅니다.

| 묶음 | 출처 | 라이선스 |
|---|---|---|
| piano-grand | Salamander Grand Piano (Alexander Holm), Tone.js 호스팅본 https://tonejs.github.io/audio/salamander/ | CC BY 3.0 |
| bass-*, piano-electric, pad-*, strings-*, guitar-*, lead-* | FluidR3_GM soundfont (Frank Wen), MIDI.js 렌더본 https://github.com/gleitz/midi-js-soundfonts | CC BY 3.0 |
| drums-boom (TR-808), drums-tight (LM-2), drums-electro (MFB-512) | smpldsnds/drum-machines https://github.com/smpldsnds/drum-machines | Public domain |

다시 받기: `npm run samples` (tools/fetch-samples.mjs)
