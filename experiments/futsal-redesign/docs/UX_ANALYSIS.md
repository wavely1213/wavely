# UI/UX 분석 — 하위 페이지 정리 (2026-10-26)

원본 futsal.or.kr 하위 페이지와 이 시안의 이전 상태(원본 본문을 정리만 해서 붙인 것)를 같이 살폈다.
기준은 frontend-design 스킬(구조는 정보다, 꾸밈보다 위계)과 ui-ux-pro-max 의 접근성·목록·표 규칙이다.

## 1. 공통 문제 — "시트를 붙인 느낌"의 원인
| 문제 | 원인 | 사용자에게 생기는 일 |
|---|---|---|
| 칸이 들쭉날쭉 | 원본이 **배치용 표**로 화면을 짬(3칸 표 + 4칸 표가 줄마다 따로) | 같은 종류인데 크기·줄이 달라 훑어보기 어렵다 |
| 의미 없는 잔해 | 원본의 검색 폼("대회년도 조회"), 상태 **그림 글자**(stepN.gif), 장식 점 이미지 | 눌리지 않는 글자, 화면낭독기가 못 읽는 상태값 |
| 날짜가 중간에서 끊김 | 좁은 칸 + 아무 데서나 줄바꿈 | "2026-02-" / "28" 처럼 읽힘 |
| 읽는 칸이 왼쪽에 쏠림 | 글 폭은 72자로 제한했는데 가운데 정렬이 없음 | 넓은 화면에서 오른쪽 절반이 빔 |
| 긴 규정이 한 덩어리 | 원본이 PDF 를 옮긴 듯 줄마다 끊긴 글 | 4만px 스크롤, 원하는 조항을 못 찾음 |
| 같은 머리글이 두 번 | "연도·개최국·우승국"을 한 줄에 두 번(좌우 2단) | 연도 순서가 지그재그 |

## 3. 지킨 것
- 글자·링크·그림은 바꾸지 않았다. 바꾼 것은 "배치"와, 글자마다 띄운 한글(`주 소`→`주소`, `정 시 운`→`정시운`)뿐.
- 새로 붙인 화면 문구: 섹션 제목 "연혁" "임원진" "선수단 N명", 안내 "대회명을 누르면 원본 사이트의 대회 상세가 새 창으로 열립니다."
- 원본 안내 "상세 정보는 경기장 클릭하면 확인 가능 합니다."는 새 화면에 상세 보기가 없어 옮기지 않았다(거짓 안내 방지).

## 4. 남은 것 (다음에 볼 것)
- 연맹정관·규정의 "1. / 가. / ①" 들여쓰기는 한 단계로만 구분한다(원본에 단계 정보가 없음).
- 풋살장 사진 상당수가 원본의 "등록된 사진이 없습니다" 그림이다 — 그대로 둠.
- 대회 상세(leagueRead)는 여전히 원본으로 연결한다.

## 5. 2차 정리 (2026-10-26)
- **기준선 측정**: 전 페이지에서 본문 글자의 시작 위치를 제목과 비교해, 2~12px 안쪽에서 시작하던 곳(표 첫 칸, 연혁, 중계·뉴스·게시판 목록, 사진 설명, 동영상)을 모두 제목과 같은 선으로 맞춤. 남은 차이는 배지 안쪽 글자와 인용 들여쓰기(의도)뿐
- **표**: 머리 줄 회색 면을 빼고 진한 선 한 줄로, 첫 칸·끝 칸 바깥 여백 0
- **다크 모드 버튼**: 화면 오른쪽 아래에 떠서 목록 날짜를 가리던 것을 상단 유틸리티 줄로
- **푸터**: 사이트맵이 7+2로 두 줄이 되던 것을 한 줄(하위 메뉴 없는 두 항목을 한 칸에), 후원사 로고 테두리 제거, 비공식 안내 띠를 노랑 → 남색
- **구단 연혁**: 줄 맨 앞 날짜가 공백으로 떨어져 있을 때만 연도 칸으로("현대해상 2017 …", "2015-16시즌 …"은 한 줄 그대로), ". 창립" 같은 앞 점 제거
- **구단 상세**: 엠블럼 칸을 280px 정사각으로 줄여 정보가 먼저 보이게
- **연맹정관**: "제1장 총 칙"·"부 칙" 글자 사이 공백 제거
- **모바일**: 로고 줄이 "전체 메뉴" 버튼과 붙던 것 정리, 하위 탭은 현재 탭이 가려질 때만 옆으로 밀기
