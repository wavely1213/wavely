# 와벨리 — 알바(구인구직) 탭 스펙 → Claude Code / 개발 그룹

> 시각·상호작용 단일 근거: `와벨리 알바탭.html` (다크 · 블루 액센트). 이 문서는 그 목업을 dev 앱(`wavely-frontend/app`)의 `JobScreen`으로 옮기기 위한 명세입니다. 하단 탭 순서: **커뮤니티 · 우리동네 · 알바 · 채팅 · 마이페이지** (알바 = 3번째, 활성 시 briefcase 채움).

## 0. 화면 골격 (위→아래)
1. **검색 헤더** — 검색 인풋("알바 검색 (예: 카페, 주말 단기)") + 테마 토글 + 알림 + 와 로고 아바타. (커뮤니티 등 다른 탭과 공유하는 상단바 재사용)
2. **타이틀** "알바" + 우측 **공고 올리기** pill(블루). 부제: "강원 춘천시 · 우리 동네 구인·구직 · 채팅으로 바로 연결".
3. **구인/구직 세그먼트** — 하나의 pill 그룹(2칩). 기본 `구인`.
4. **정렬 칩** — 가까운순 / 시급순 / 최신순(기본). 단일 선택(radio). **실제 재정렬**.
5. **카테고리 칩** — 전체 / 요식·카페 / 매장·판매 / 서비스 / 배달·운송 / 사무·기타. **다중 선택 + 드래그 페인팅**.
6. **결과 요약 줄** — "N건의 공고" + 우측 **위치 버튼**(기본 "현재 위치", 탭 시 동네 선택 시트).
7. **공고 리스트** — 구인=매장 공고 카드 / 구직=구직자 카드.

## 1. 데이터 모델
```ts
type Category = 'food'|'retail'|'service'|'delivery'|'office';
// 구인 (매장이 올림)
interface Hire {
  id; storeId; store; cat: Category; dong;      // dong = 동 이름(필터 키)
  vf: boolean;          // 사업자 인증
  ad: boolean;          // 광고/상위노출 (마커·카드 강조 + 정렬 우선)
  loc;                  // "효자동 · 200m"  (거리 파싱해 가까운순 정렬)
  title; pay: number; monthly?: boolean;         // monthly=true면 월급, 아니면 시급
  sched; tags: string[]; time; applied: number;  // 지원자 수
}
// 구직 (개인이 올림 — 익명 원칙)
interface Seek {
  id; cat: Category; dong; loc;
  title; pay: number;   // 희망 시급
  sched; tags: string[]; time;
  state: 'open'|'sent'|'accepted';               // 러브콜 상태 (아래 §4)
  ageBand;              // 공개 전 노출용: "20대 중반"
  gender;               // "여"/"남"
  // ↓ 수락(accepted) 시에만 공개
  name; age: number; contact; career;
}
```
- 카테고리 색(마커·로고): food `#E0692E` · retail `#2F77F0` · service `#C24FD0` · delivery `#17A75C` · office `#7A2BC4`. 인증 배지 그린 `#17A75C`.

## 2. 정렬 (실제 동작)
- **가까운순**: `loc`에서 거리 파싱(`m`/`km`) 오름차순. 좌표가 있으면 현재위치 대비 실거리로 대체.
- **시급순**: 급여 내림차순. 월급은 시급 환산(`pay/209`)해서 혼합 정렬.
- **최신순**(기본): 등록시각 최신순(목업은 배열 원순서).

## 3. 필터 (카테고리 + 동네)
- **카테고리**: 다중 선택 Set. 비어있으면 전체. 칩 탭=토글, **드래그**하면 지나가는 칩을 첫 칩 상태로 일괄 칠함(pointerdown+capture, pointermove에서 `elementFromPoint`로 대상 칩 판정). 선택 칩엔 체크 아이콘.
- **동네**: 기본 빈 Set = **"현재 위치"**(GPS, 라벨 "현재 위치"). 위치 버튼 탭 → 바텀시트. 시트에 "현재 위치 기준" 리셋 행 + 춘천 동 목록(효자·석사·후평·퇴계·온의·조운·신사우·근화·소양) 다중 토글. 라벨: 0개="현재 위치", 1개="효자동", N개="효자동 외 (N-1)". 필터는 `dongs`에 매칭.
- 두 필터는 AND. 리스트·건수 실시간 갱신.

## 4. 구직 익명 → 러브콜 → 인적사항 공개 (핵심 플로우)
개인정보 보호를 위해 **구직 글은 익명 원칙**. 상태 머신:
- **open** (기본): 카드에 "익명 · {ageBand} · {gender}"만 노출. 실명·연락처·경력 숨김. 안내문 "러브콜을 수락하면 실명·연락처·경력이 공개돼요"(자물쇠 아이콘). 액션 = **러브콜 보내기**(하트).
- **sent**: 매장이 러브콜 발송. 액션 = **수락 대기중**(시계, disabled). 구직자에게 알림 전송.
- **accepted**: 구직자가 수락 → 카드에 실명·성별·나이 + **공개됨** 배지(그린), 하단에 **연락처·경력** 공개 블록, 액션 = **채팅하기**.
- 서버: `love_call(id, hire_store_id, seek_id, status)` 테이블. 상태 전이는 seek 소유자 동의(accepted) 시에만 개인정보 조인 노출. **accepted 전에는 API 응답에서 name/contact/career를 절대 내려주지 말 것**(클라 마스킹이 아니라 서버 차단).
- 목업에선 러브콜 클릭 → `sent` → 1.5s 후 `accepted`로 시뮬레이션(데모용). 실제는 상대 수락 이벤트로 갱신.

## 5. 카드 스펙
**구인 카드**: [업종색 로고+글리프] 상호+인증배지 · 거리 / 제목(17px 800) / **시급 or 월급(블루 강조)** · 근무시간 / 태그(카테고리 pt칩 + 조건칩) / 구분선 / "N분 전 · 지원 N" + 저장 + **채팅 지원**. 광고 공고는 블루 링 + "광고" 칩 + 정렬 상단 고정.
**구직 카드**: 원형 아바타(open=익명 person 글리프/회색, accepted=이름 이니셜+업종색) / 신원줄(§4) / 제목 / **희망 시급**(중립색) · 시간 / 태그 / 공개·비공개 블록(§4) / "N분 전 등록" + 액션(§4).

## 6. 빈 상태
필터 결과 0건 → "해당 조건의 구인/구직 글이 없어요". 전체 0건(신규 동네) → 기존 빈 화면("구인 공고가 아직 없어요 · 첫 공고를 올려 우리 동네에 알려보세요" + 공고 올리기) 유지.

## 8. 모바일(앱) 카테고리 다중선택 — 드래그 페인팅 폐기 ★

웹의 드래그 페인팅은 모바일에서 **가로 스크롤과 충돌**합니다. 앱·웹 모두 아래로 통일합니다.

- **칩 탭 토글** — 누르면 켜지고 다시 누르면 꺼집니다. 켜진 칩에 체크 글리프가 슬라이드로 들어옵니다(`.ck` width 0→13px).
- **'전체' = 리셋 칩** — 좌측 고정. 선택이 없으면 활성(파랑), 선택이 있으면 `.has-sel`로 중립 배경 + **× 글리프**가 나타나 "누르면 초기화"를 알립니다. 선택 상태를 겸하는 게 아니라 **동작 버튼**입니다.
- `pointerdown/pointermove/setPointerCapture` 전부 제거, `click` 하나로. `touch-action:pan-x`·`cursor:grab` 제거 → 가로 스크롤이 정상 동작합니다.
- **결과 요약줄에 적용 필터를 표기**합니다: `4건의 공고 · 요식·카페 외 1`. 칩이 스크롤로 화면 밖에 있어도 무엇이 걸려 있는지 보입니다.
- 결과 요약줄의 위치 버튼(`현재 위치 ▾`)은 그대로 유지 — 동네 시트를 여는 유일한 입구입니다.

## 9. 앱 카드의 업종색 사용 범위 ★

업종색은 **두 곳까지만** 씁니다. 더 늘리면 카드가 알록달록해져 시급·제목이 안 읽힙니다.

| 위치 | 업종색 | 비고 |
|---|---|---|
| 카드 아바타 (42px) | **배경 = 업종색, 글리프 = 흰색** | 웹과 동일. 구직 카드는 원형 |
| 카테고리 태그칩 | **글자 = 업종색, 배경 = 업종색 13%**(hex+`22`) | 기존 파랑 `.tag.pt` 대체 |
| 제목 · 시급 · 버튼 · 나머지 태그 | 사용 안 함 | 시급=블루, 나머지=중립 |
| 광고 링/칩 | 사용 안 함 | 브랜드 스카이 |

- 업종색: 요식·카페 `#E0692E` · 매장·판매 `#2F77F0` · 서비스 `#C24FD0` · 배달·운송 `#17A75C` · 사무·기타 `#7A2BC4`.
- **`사무·기타 #7A2BC4`는 브랜드색이 아닙니다.** 스카이 전환 대상에서 제외 — 그대로 둡니다.
- 구직 카드 익명 아바타는 업종색을 쓰지 않습니다(`.seek-anon`, 중립 회색). 러브콜 수락 후 실명 공개 시점에 업종색 아바타로 바뀝니다.
