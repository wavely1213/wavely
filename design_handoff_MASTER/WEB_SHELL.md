## 2. A-3. 상단바 아바타 — 상태별 동작 (확정)

| 상태 | 표현 | 클릭 | 툴팁 |
|---|---|---|---|
| 로그인 | 이니셜 아바타 32px (`Av`) | **마이페이지로 이동** | `{닉네임} · 마이페이지` |
| 비로그인 | **점선 링 28px + 회색 person 글리프 + "로그인" 라벨 pill** | **로그인 모달** | `로그인` |

```css
.web-guest{display:flex;align-items:center;gap:7px;height:38px;padding:0 12px 0 5px;
  border-radius:999px;border:1px solid var(--line);color:var(--ink2)}
.web-guest-av{width:28px;height:28px;border-radius:50%;
  border:1.5px dashed var(--ink3);color:var(--ink3)}
.web-guest:hover{border-color:var(--primary);color:var(--primary-deep)}
```

**규칙**
- 로그인 상태에서 **로그인 모달을 절대 띄우지 않습니다**(무한 로그인창의 원인).
- 비로그인이면 아바타를 이니셜로 만들지 않습니다 — 이니셜은 "누군가로 로그인됨"을 뜻하므로 게스트에게 쓰면 거짓 신호입니다. **점선 = 미확정**, 라벨로 다음 동작을 명시.
- 비로그인일 때 **알림 벨은 숨깁니다**(알림받을 주체가 없음).
- 비로그인이 `마이페이지`·`채팅`·`글쓰기`를 누르면 → 로그인 모달. 라우트로 진입시키지 않습니다.
- 로그인 → 로그아웃 전환 시 현재 라우트가 `mypage`면 `community`로 되돌립니다.

## 3. B-1. 사이드바 세로 오버플로 (확정)

**(a) 전체 스크롤 + (d) 컴팩트 모드** 조합입니다.

### 3-1. 기본 — 항상 스크롤 가능
```css
.web-sidebar{overflow-y:auto;overflow-x:hidden}
.web-logo,.web-loc,.web-nav,.web-side-card{flex:none}
.web-write-btn{flex:none;min-height:46px}   /* 눌려 납작해지지 않음 */
.web-side-spacer{flex:1 1 auto;min-height:16px}  /* 버튼↔카드 최소 간격 보장 */
```
스크롤바 6px. 최소 보장값(글쓰기 46px 고정, 버튼↔카드 ≥16px)은 개발 임시조치와 동일하게 확정합니다.

### 3-2. 컴팩트 모드 — **창 높이 < 720px**
`ResizeObserver`로 셸 높이를 관찰해 `.web-app`에 `side-compact`를 토글합니다(뷰포트 미디어쿼리 아님 — 셸이 상위 컨테이너 안에 들어가도 동작).

| 요소 | 기본 | 컴팩트 |
|---|---|---|
| 사이드바 폭 | `--sidebar` | **76px** |
| 로고 | 마크 + "와벨리" | 마크만, 중앙 |
| 지역선택 | 핀 + 지역명 + ▾ | **핀만**, 툴팁에 지역명 |
| 메뉴 5 | 아이콘 + 라벨 | **아이콘만**, 툴팁에 라벨 |
| 채팅 배지 | 숫자 pill | **8px 도트**(우상단) |
| 글쓰기 | 아이콘 + "글쓰기" | 아이콘만 · **높이 46px 유지** |
| 사장님 카드 | 3줄 카드 | **44px 아이콘 버튼**(`.web-side-mini`, #14212B) |
| 법적 푸터 | 표시 | **숨김** |

- 라벨 숨김은 `.web-lbl{display:none}` 한 줄로 처리합니다 — 마크업을 분기하지 않습니다.
- 컴팩트에서는 `overflow:visible`(내용이 짧아 스크롤 불필요).
- 컴팩트여도 사이드바 접기(`nav-collapsed`)는 그대로 동작합니다. 두 상태는 독립입니다.
- **1280×480 실측**: 좌하단 제거 + 컴팩트 적용으로 넘침 0px.
