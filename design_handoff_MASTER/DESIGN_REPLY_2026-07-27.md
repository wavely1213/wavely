## B. 디자인 결정 — 답변

### B-1. 사이드바 세로 오버플로 → **(a) + (d) 조합** ✅
전체 스크롤 허용 + **창 높이 720px 미만에서 컴팩트 모드**(폭 76px, 아이콘만, 사장님 카드 44px 아이콘, 법적 푸터 숨김). 글쓰기 46px 고정과 버튼↔카드 ≥16px는 임시조치대로 확정. 목업 상태 바에서 480px까지 직접 확인 가능. → WEB_SHELL.md §3

### B-2. 축제 탭 상태 5종 ✅ 전부 디자인
1. **타임테이블 빈 상태** — 날짜칩은 점선으로 남기고 "9월 중 공개 예정" 칩 + 유령 슬롯 3개. 스켈레톤 애니메이션 없음(로딩이 아니라 미공개).
2. **타임슬롯 상세 시트** — 유형칩→제목→시간→메타→설명→CTA 2개. 빈 필드는 행 삭제.
3. **지도 폴백** — 높이 200px 동일 유지 + 주소·카카오 길찾기·대중교통 항상 렌더 + 폴백에서만 문의 전화. 재시도 버튼 없음.
4. **참여업체 미정** — 3단 진행 표시(모집→선정→공개) + 모집공고 + 사장님 신청 밴드. **지도는 렌더 안 함.**
5. **진입 배너** — 그라데이션 폐기, 솔리드 오렌지. 커뮤니티=56px 바 / 우리동네=88px 카드, **동시에 한 곳만**, 닫으면 7일.

+ 홈 구성을 개발 순서대로 정본화하고 **서브탭 3분할을 폐기**했습니다.

### B-3. 동네레벨 앱 제약 ✅
- **앱 링 = 선형 3스톱 정본** 9종 확정(135° 대각, offset 0/.5/1, stroke 3.5, 간격 2px). 목업 F 탭에서 웹 conic과 44px 나란히 대조.
- **앱 이펙트 범위 확정**: 다이아 회전 10s만 유지 · 파티클 4종 전부 미적용(메달로 대체) · 승급 광선은 PNG 스프라이트.
- **앱 아이템 도감 신설**(목업 G 탭): 전체화면 푸시 + 세그먼트 3분할 + 3열 그리드 + 하단 저장 바. 웹은 즉시 반영이지만 앱은 **저장 시 커밋**.
- 이펙트 강도 **70%**로 하향(주기·피크 알파 전부 조정).
- 배경 아이템 보류 해제 → **9종 전량 채택**(정적 8 + 애니 1). 틴트가 장소의 색을 갖습니다.

### B-4. 알바 탭 앱 축소 구현 ✅
- **드래그 페인팅 폐기** → 칩 탭 토글 + '전체' 리셋 칩(× 글리프). 앱·웹 통일. 가로 스크롤 정상화.
- 결과 요약줄에 **적용 필터 표기** 추가(`4건의 공고 · 요식·카페 외 1`), 위치 버튼 유지.
- **업종색은 두 곳까지**: 카드 아바타(배경+흰 글리프) + 카테고리 태그칩(글자+13% 틴트). 제목·시급·버튼·광고는 사용 안 함.
