# 와벨리 — 축제 이벤트 탭 스펙 → Claude Code / 개발 그룹

> 시각·상호작용 단일 근거: `와벨리 축제탭.html` (다크 · 블루 액센트 + 닭갈비 warm 포인트). "우리동네" 안의 **로컬 축제 이벤트** 상세 화면. 첫 사례: **2026 춘천닭갈비·막국수축제** (9.4금~9.6일, 명동·축제장 일대).

## 0. 구성
상단바(뒤로·좋아요·공유) → **히어로 배너**(축제명·기간·장소·D-day, warm 그라데이션) → **서브탭 3개**: 타임테이블 · 행사장 안내 · 닭갈비·막국수. 하단은 앱 공통 5탭(진입은 우리동네/커뮤니티 배너에서).

## 1. 타임테이블
- **데이 칩**(9.4금 / 9.5토 / 9.6일) 단일 선택 → 해당 날짜 타임라인.
- **세로 타임라인**: 좌측 시각(굵게) + 노드 + 카드(유형 태그·제목·장소). 유형: `show`(공연·블루) / `food`(먹거리·warm) / `exp`(체험·그린). 노드 색은 유형 따라, 대형 이벤트(`big`: 드론쇼·콘서트·불꽃놀이·폐막)는 노드 확대+글로우.
- 이벤트 필드: `{ t(시각), title, loc(장소명), zone(행사장 구역 id), type, big? }`.

## 2. 행사장 안내 (지도 + 위치별 행사)
- **벡터 축제장 맵**(광장·강·도로·녹지 stylized) 위에 **번호 핀**(구역). 구역: 1 메인무대 · 2 먹거리존 · 3 체험존 · 4 이벤트존 · 5 플리마켓 · 6 입구·안내소.
- **핀 탭 → 바텀시트**: 구역명 + 그 구역(zone)에서 열리는 **전 일정**(모든 날짜 교차 집계, 예: 메인무대 = 드론쇼/콘서트/불꽃놀이/폐막). 데이터는 타임테이블 EVENTS에서 `zone` 매칭으로 자동 수집 — 별도 입력 불필요.
- 구역 좌표 `{ x, y }`(% 기준), 아이콘 path 포함.

## 3. 닭갈비·막국수 (업체 핀 → 업체 정보)
- 같은 맵 베이스에 **업체 핀**: 닭갈비 warm `#E9603F`, 막국수 블루 `#34A8E1` (핀 안 업종 아이콘).
- 상단 **필터 토글**: 전체 / 닭갈비 / 막국수.
- **핀 탭 → 바텀 업체 카드**: 상호 + 업종 배지 · ★평점·리뷰·거리 · 태그(메뉴/가격/특징) · 축제 한정 안내(note, 있을 때) · **[업체 정보 보기]** 버튼.
  - 버튼 → **우리동네 매장 상세**로 라우팅(`storeId` 연결). 축제 업체는 기존 `stores` 레코드에 `festivalId` 태그를 달아 재사용 권장.
- 업체 필드: `{ id, storeId, name, kind:'dak'|'mak', x, y, rating, reviews, dist, tags[], note }`.

## 4. 데이터 모델 (서버)
```ts
interface Festival { id; name; start; end; area; heroTheme; }
interface FestZone { id; festivalId; n; name; x; y; icon; }
interface FestEvent { id; festivalId; day; time; title; loc; zoneId; type:'show'|'food'|'exp'; big:boolean; }
interface FestVendor { id; festivalId; storeId; kind:'dak'|'mak'; x; y; note; } // 표시정보는 storeId 조인
```
- 좌표(x,y)는 축제장 맵 기준 %. 실제 지도 연동 시 위경도 → 지도 SDK 마커로 대체(핀 디자인·시트는 동일).

## 5. 토큰
알바 탭과 동일(다크 블루) + 축제 포인트 `--warm #E9603F` / `--warm-soft rgba(233,96,63,.15)`. 히어로 그라데이션 `linear-gradient(135deg,#2A1410,#16223A)`.

## 6. 확장 여지 (선택)
- 편의시설 핀(주차·셔틀·화장실) 레이어 토글, 즐겨찾기한 일정 알림(D-day·시작 30분 전), 실시간 "지금 진행중" 표시(축제 기간 중), 셔틀 노선. 현재 목업은 요청 3종(타임테이블·행사장 맵·업체 핀)에 집중.
