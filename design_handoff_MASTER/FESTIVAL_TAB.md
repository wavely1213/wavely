## 1. 토큰 — 축제 전용 오렌지

축제 탭 **안에서만** 브랜드색을 오렌지로 바꿉니다. 앱의 나머지(탭바·링크·일반 버튼)는 **스카이 유지**.

```css
--fest:#F26D1F; --fest-deep:#C7500F; --fest-soft:#FDECE0; --fest-line:#F7C9A8;
/* dark */ --fest:#FF8A45; --fest-deep:#FFA96F; --fest-soft:#2A1710; --fest-line:#4A2818;
--dak:#E8461E;  /* 닭갈비 */   --mak:#2A9D8F;  /* 막국수 */
```
- 오렌지를 쓰는 곳: 히어로 배경 · 진입 배너 · 퀵버튼 아이콘 · 타임라인 시각 · D-day · 대형이벤트 노드 글로우 · 진행단계 표시.
- 닭갈비/막국수 색은 **업체 구분에만**. 히어로나 버튼에 쓰지 않습니다.
- **그라데이션 금지.** 솔리드 오렌지로 고정했습니다 — 스카이 톤 안에서 색이 다른 것만으로 이미 충분한 신호이고, 질감까지 얹으면 광고처럼 보입니다.

## 3. B. 축제 홈

- **히어로**: 배지("2026 로컬 축제") → 축제명 24px/800 → 기간·장소 메타 → 우하단 D-day. 우상단 흰 원형 광채 1개(불투명도 .12)로 깊이만.
- **퀵버튼 4**: 전화 · 길찾기 · 인스타 · 공식홈. 64px 정사각, 아이콘만 오렌지.
- **축제 한눈에**: 기간 / 장소 / 입장료 / 주최 4행. 키 62px 고정폭.
- **관람안내 타일 6**: 주차 · 셔틀버스 · 화장실 · 안내소(유실물) · 반려동물 · 우천 시. 3열 그리드, 각 타일 = 아이콘 + 이름 + 2줄 요약.
- **푸터**: 주최·주관 / 문의 / "프로그램은 우천·현장 사정에 따라 변경될 수 있습니다."

> **섹션은 실데이터가 있을 때만 렌더.** 프로그램 미공개 → §4의 빈 상태, 업체 미선정 → §7의 모집 상태로 **대체**합니다. 빈 섹션 헤더만 남기지 마세요.

## 4. C. 타임테이블 — 빈 상태 ★

날짜(10.14~18)는 확정됐지만 일정은 미공개인 구간이 실제로 가장 깁니다.

- **날짜칩은 남깁니다** — 점선 테두리(`.dchip.soon`) + 숫자 회색. "확정된 날짜, 미확정 내용"을 형태로 구분. 탭은 되지만 아래 내용은 바뀌지 않고 선택 표시도 없습니다.
- **안내 카드**(`.empty`, 오렌지 soft + 점선): 아이콘 48 → "프로그램 준비 중이에요" → 2줄 설명 → **공개 시점 칩** → CTA 2개.
- **유령 슬롯 3개**를 투명도 55%로 아래에 깔아 "여기에 시간표가 들어온다"를 형태로 알립니다. **스켈레톤 로딩 애니메이션은 넣지 않습니다** — 로딩이 아니라 미공개라서요.
- **공개 시점은 반드시 문구로.** "곧 공개" 금지 → "9월 중 공개 예정"처럼 **월 단위**. 값은 `festival.programPublishAt`. 미정이면 이 칩을 숨기고 알림 버튼만.
- CTA: `[작년 프로그램]`(전년도 데이터 있을 때만) + `[공개 알림 받기]`. 전년도가 없으면 알림 버튼 1개를 폭 100%로.

## 5. D. 타임슬롯 → 상세 바텀시트 ★

슬롯 탭 → 시트. 페이지 이동이 아닌 이유: 하나 보고 바로 다음 슬롯으로 돌아가는 게 기본 동작입니다.

**순서 고정**: 유형칩 → 제목 → 시간(오렌지) → 메타 → 설명 → CTA 2개.
시간을 제목 위가 아니라 **아래** 두는 건, 목록에서 이미 시간을 보고 눌렀기 때문입니다.

| 요소 | 스펙 |
|---|---|
| 유형칩 | `show` 공연=스카이 / `food` 먹거리=닭갈비색 / `exp` 체험=그린 |
| 시간 | `10.17(토) 18:00 ~ 19:30` · 오렌지 800 |
| 메타 | 장소(구역 링크) / 소요 / 요금 — **빈 필드는 행 자체를 삭제** |
| 설명 | `desc` 없으면 블록 통째로 생략 |
| CTA | `[지도에서 보기]` + `[내 일정에 담기]` · 유료는 후자를 `[예약하기]`로 |

- 높이 내용에 따라 자동, **최대 78%**. 그립은 드래그 핸들(아래로 끌어 닫힘).
- 축제 기간 중 진행 중인 슬롯은 시간 옆에 점 + "지금 진행중".
- 일정 담기 → 시작 **30분 전** 알림.

## 6. E. 오시는 길 — 지도 폴백 ★

지도 SDK 미인증·쿼터 초과·오프라인 대비. **주소와 길찾기는 지도 없이도 되는 일**이라 폴백에서도 끝까지 갈 수 있게 만듭니다.

- **폴백 높이를 지도와 똑같이(200px)** 잡습니다. 더 납작해지면 아래 콘텐츠가 튀어 올라 "무언가 사라졌다"로 읽힙니다. 점선 테두리 + 회색으로 "자리는 있으나 비었음".
- 문구: "지도를 불러올 수 없어요 / 잠시 후 다시 시도해 주세요. 아래 주소로 길찾기는 바로 가능해요."
- **주소·길찾기·대중교통 3블록은 항상 렌더** (지도 성공/실패와 무관한 정적 데이터). 폴백에서만 **문의 전화 행**을 추가.

### 길찾기 = 네이버 지도 (확정)
지도 SDK가 네이버(`NAVER_MAPS.md`)이므로 길찾기도 네이버로 통일합니다. 지도와 길찾기가 다른 서비스면 좌표 기준이 어긋나고 사용자도 두 앱을 오가게 됩니다.

| 항목 | 값 |
|---|---|
| 앱 스킴 | `nmap://route/public?dlat={lat}&dlng={lng}&dname={인코딩된 장소명}&appname=kr.wavely` |
| 웹 폴백 | `https://map.naver.com/p/directions/-/{lng},{lat},{장소명}` |
| 버튼 | 높이 46 · radius 13 · **배경 #03C75A / 글자 #FFF** (네이버 가이드값 — 오렌지로 바꿀 수 없음) |
| 아이콘 | 중립 내비게이션 화살표. 타사 로고 마크를 그려 넣지 않습니다 |
| 자동차/대중교통 | `route/public`(대중교통) 기본. 주차 안내가 있는 축제는 `route/car` 병기 가능 |

- 퀵버튼의 `길찾기`와 오시는 길의 큰 버튼은 **같은 딥링크**를 씁니다.
- 앱 미설치 감지는 스킴 호출 후 1.2초 내 blur 없음 → 웹 폴백.
- **재시도 버튼은 넣지 않습니다.** 탭 재진입 시 자동 재시도로 충분하고, 실패 화면의 버튼은 눌러도 안 되는 경험을 반복시킵니다.

## 7. F. 참여업체 — 미정 상태 ★

빈 목록을 숨기는 대신 **모집 중이라는 사실을 콘텐츠로** 씁니다(사장님 유입 경로도 됩니다).

- **3단 진행 표시**: 모집(8.1~8.20) → 선정(8월 말) → 공개(9월 중). 현재 단계만 오렌지. 미정 단계는 월 단위 표기.
- CTA: `[공개 알림]` + `[모집 공고 보기]`.
- **사장님 신청 줄**(오렌지 soft 밴드)은 **미정 상태에서만**. 업체 확정 후 사라집니다 — 마감 후에 남으면 신청할 수 없는 버튼이 됩니다.
- **지도는 미정 상태에서 렌더하지 않습니다.** 핀 없는 빈 지도는 정보가 0인데 화면의 40%를 씁니다. 업체 확정 후 지도+핀이 이 자리에 들어옵니다.
- 확정 후: 필터칩(전체 N / 닭갈비 N / 막국수 N) + 2열 카드 그리드.
- 필터칩은 날짜칩(`.dchip`)을 재사용하지 말고 **전용 `.vfilter`**를 씁니다(날짜칩은 세로 2단 조판이라 한 줄 텍스트가 깨집니다). `inline-flex` row · height 32 · radius 999 · `white-space:nowrap`, 숫자는 `<i>`로 감싸 opacity .72.

### 7-1. 매장 대표사진 ★
**사진이 카드의 주인공입니다.** 로고 중심 카드에서 사진 중심 카드로 바꿨습니다 — 먹거리 축제에서 업체를 고르는 판단 재료는 업종 아이콘이 아니라 음식 사진입니다.

| 요소 | 스펙 |
|---|---|
| 사진 | 카드 상단 **전체 폭**, `aspect-ratio:16/11`, `object-fit:cover` |
| 소스 | 매장 레코드의 `photos[0]` — **축제용으로 따로 올리지 않습니다** |
| 업종 배지 | 사진 **좌하단 26px** 라운드 스퀘어(업종색 + 흰 글리프) + 그림자 |
| 사진 없음 | **업종색 단색 배경 + 흰 글리프 중앙** 폴백. 회색 빈 박스·깨진 이미지 아이콘 금지 |
| 본문 | 사진 아래 10/11px 패딩 · 상호 13.5/800 (1줄 생략) · ★평점·거리 11.5 · 업종 배지 |
| 로딩 | 사진 영역만 `--field` 단색. 스켈레톤 셔머 없음(카드가 2열 다수라 산만해집니다) |

- 목업에는 `<image-slot>`(id `fest-v1`~`fest-v4`)을 넣어 실사진을 드래그로 끼워 확인할 수 있게 했습니다. **구현에는 슬롯이 아니라 `<img>`가 들어갑니다.**
- 지도 핀 안의 사진은 `NAVER_MAPS.md`의 원형 40px 규격을 따릅니다(같은 `photos[0]`).
- 업체 카드는 **기존 매장 레코드 재사용**(`storeId` 조인) — 축제용 정보를 따로 입력하지 않습니다. 탭 → 우리동네 매장 상세.

## 8. 데이터 모델

```ts
interface Festival {
  id; name; start; end; area; theme:'orange';
  programPublishAt?: string;   // '2026-09' — 없으면 공개시점 칩 숨김
  vendorState: 'recruiting'|'selecting'|'published';
  vendorRecruitEnd?: string; noticeUrl?: string;
  lat; lng; address; tel; instagramUrl?; homepageUrl?;
}
interface FestEvent { id; festivalId; day; start; end?; title; loc; zoneId?;
  type:'show'|'food'|'exp'; big:boolean; desc?; fee?; durationMin?; reservable:boolean; }
interface FestVendor { id; festivalId; storeId; kind:'dak'|'mak'; note?; }
// 표시정보(상호·평점·거리·photos[0])는 전부 storeId 조인 — 축제 테이블에 복제하지 않음
interface FestGuide { id; festivalId; key:'parking'|'shuttle'|'toilet'|'info'|'pet'|'rain'; summary; }
```
- `FestEvent`가 0건 → C의 빈 상태. `vendorState !== 'published'` → F의 모집 상태.
- 지도 좌표는 실 위경도. 지도 실패 판정은 SDK 로드 실패 + 5초 타임아웃.
- 지도·길찾기 모두 **네이버**. 카카오 경로는 쓰지 않습니다(§6).

## 9. 접근성 · 반응형

- ≤760px 단일 컬럼. 히트 타깃 44px 이상(퀵버튼 64, 날짜칩 60, CTA 44).
- 라이트/다크 모두 정의. 오렌지는 다크에서 한 톤 밝게(#FF8A45).
- 오렌지 위 흰 글자 대비: #F26D1F + #FFF = 3.4:1 → **14px 이상 700 이상**에서만 사용. 작은 캡션은 흰색 92% 대신 순백 유지.
- 시트·스크림은 `role="dialog"` + Esc 닫기 + 포커스 트랩.
