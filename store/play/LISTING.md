실물과 다르면 반려됩니다.

2. **커뮤니티** — 글 목록
3. **알바** — 공고 목록
4. **축제** — 히어로 포스터가 보이는 화면

6. (선택) 마이페이지

## 콘텐츠 등급 설문 — 예상 답안

사용자 간 소통(게시글·댓글·1:1 채팅)이 있어 **전체이용가는 안 나옵니다.**
설문에서 아래를 사실대로 체크해야 합니다:

- 사용자 간 상호작용 **있음** (게시판·채팅)
- 사용자 생성 콘텐츠 공유 **있음**
- 위치 공유 **있음** (거리·지도 기반)
- 폭력·성적 콘텐츠·도박·약물 **없음**
- 디지털 구매 **없음** (v1은 앱 내 결제 미제공)

→ 보통 **만 12세 이상** 근처가 나옵니다. 실제 등급은 설문 결과로 자동 산출됩니다.

★ 사용자 생성 콘텐츠가 있으면 구글이 **신고·차단 기능**을 요구합니다.
  앱에 이미 있습니다(글·댓글 신고, 채팅 1:1 신고/차단) — 심사 질문에 그렇게 답하면 됩니다.
